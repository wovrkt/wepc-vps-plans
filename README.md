## 几个下单前常问的问题

**流量跑超会停机吗？**
美国 9929 系列前四款写的是限速 3Mbps，不停机、不额外扣费。高配款没有写明处理方式，需要单独确认。

**能装 Windows 吗？**
官网有 Web_Email_Windows_VPS 这条产品线，具体给不给授权、加不加钱，看对应套餐页的说明。

**优惠码能叠加吗？**
两个码分别对应月付季付和年付，没有叠加的说法。适用套餐有限制，中国台湾、新加坡、部分美国住宅宽带系列和特殊线路不参与。

**用起来有什么协议限制？**
美国店页面顶部明确写了严禁使用 shadowsocks 协议。这一条对部分用途是硬性排除项，付款前先看清楚，别等开通了才发现用不了。

**续费会涨价吗？**
页面没有单独的续费价，折扣码是否循环生效也没标注。续费前在购物车核对实际金额。
